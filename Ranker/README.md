# IndicClaimVer 2026: Ranker Module (Subtask 2)

A high-performance, multi-stage document and sentence reranking system tailored for Indic language claim verification and fact-checking workflows (supporting English, Bengali, Hindi, and code-mixed inputs).

---

## 📌 Pipeline Integration Layout

When cloned into the parent `Indic_Claim_Ver` repository as `Ranker`:

```text
Indic_Claim_Ver/
├── Main/                               # Main orchestrator (Synchronizes execution)
│   └── main.py
├── Retrieval/                          # Retrieval module
│   └── main.py
├── Ranker/                             <-- OUR RANKER MODULE LOCATION
│   ├── __init__.py
│   ├── main.py                         # Clean entry point: python Ranker/main.py
│   ├── ranker.py                       # 2-Stage BGE-M3 + mMARCO Reranker Engine
│   ├── utils.py                        # Safe atomic JSON reader & writer
│   ├── requirements.txt
│   └── README.md
├── LLM/                                # LLM Verifier module
│   └── main.py
└── Output/                             # Target Pipeline Data Directory
    ├── Retrieved_Output                # Pre-defined INPUT path: \Indic_Claim_Ver\Output\Retrieved_Output
    ├── Ranker_Output                   # Pre-defined OUTPUT path: \Indic_Claim_Ver\Output\Ranker_Output
    └── Submission.json                 # Generated by LLM module
```

## 💻 Prerequisites & Setup

### 1. PyTorch CUDA Installation (For GPU Acceleration)
For system GPUs (RTX 4050, RTX 3000/4000 series, A100, H100, etc.):

```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

### 2. Module Requirements Installation
```bash
pip install -r requirements.txt
```

## ⚙️ Module Usage & Pre-Defined Paths

### Defined Input & Output Locations Inside `main.py`:
- **Input Path**: `\Indic_Claim_Ver\Output\Retrieved_Output`
- **Output Path**: `\Indic_Claim_Ver\Output\Ranker_Output`

### Clean Execution Command
No path arguments are required on the command line! Simply run:

```bash
# Executed by Main orchestrator from parent directory
python Ranker/main.py [total_count]
```

Or from inside `Ranker/`:

```bash
python main.py [total_count]
```
